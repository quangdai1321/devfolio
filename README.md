# devfolio

A modern personal developer portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Build and lint

```bash
npm run lint
npm run build
```

## Customize content

Update placeholder portfolio data in:

- `src/data/portfolio.ts`

The downloadable CV placeholder file is available at:

- `public/cv-placeholder.pdf`
